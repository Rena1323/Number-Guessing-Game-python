# Number-Guessing-Game-python

Hello everyone! This is a study project designed to test your personal skills and knowledge in programming in Python and using git.
Project: https://roadmap.sh/projects/number-guessing-game

**How to start:**

```sh
# 1. Clone This repo
git clone https://github.com/Rena1323/Number-Guessing-Game-python.git
# 2. Enter to project directory
cd Number-Guessing-Game-python
# 3. Start with python in your shell
python src/number_guessing_game_python/__init__.py
# or if you have "uv"
uv run number-guessing-game-python
```
